# README projektu

README projektu będzie opisywać sposób konfiguracji i użycia aplikacji.

## Konfiguracja i użycie

> Użyj Bash do wykonywania poleceń.

1. Zainstaluj zależności:

```bash
npm install
```

2. Wygeneruj plik `.env`:

```bash
npm run generate_env
```

3. Wypełnij bazę danych przykładowymi danymi:

```bash
npm run populate_db
```

4. Uruchom serwer:

```bash
npm run dev
```

5. Otwórz w przeglądarce:

```text
http://localhost:3000
```
